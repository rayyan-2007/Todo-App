# Todo Task Manager

A simple and responsive Todo Task Manager built with React.

This project helps users manage their daily tasks by allowing them to create, edit, delete, and update the status of tasks.

## Features

- Add new tasks
- Add task descriptions
- Edit existing tasks
- Delete tasks
- Update task status
- Filter tasks by status
- Responsive UI
- Clean and modern design

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite

## React Concepts Practiced

- Components
- Props
- useState
- Event handling
- Conditional rendering
- Array methods
- State management
- Parent-child communication
